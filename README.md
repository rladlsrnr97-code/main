# photo-id-web — 브라우저용 증명사진 생성기

데스크톱판(`../photo-id/`)을 웹으로 옮긴 것. **폰·PC 어디서나 브라우저만 있으면
동작하고, 사진은 기기 밖으로 나가지 않는다** — 모델 추론까지 전부 브라우저 안에서
돈다. 서버가 필요 없어서 정적 호스팅에 그대로 올릴 수 있다.

## 띄우기

ES 모듈을 쓰므로 `file://` 로 열면 안 되고 HTTP로 서빙해야 한다.

```bash
python -m http.server 8777
```

→ http://localhost:8777

## 배포

정적 파일뿐이라 아무 정적 호스팅에나 올리면 된다.

- **GitHub Pages**: 이 폴더를 리포지토리에 올리고 Settings → Pages → 브랜치 지정.
  주소를 폰 브라우저에서 열고 "홈 화면에 추가"하면 앱처럼 쓸 수 있다.
- Netlify / Cloudflare Pages / Vercel: 폴더를 끌어다 놓으면 끝.

**HTTPS로 서빙할 것.** 카메라 촬영 버튼(`capture`)이 보안 컨텍스트를 요구한다.

## 구성

| 파일 | 역할 |
|---|---|
| `specs.js` | 규격 프리셋 11종 + 인화지 정의 (파이썬판 `specs.py` 이식) |
| `pipeline.js` | 인물 분리 · 얼굴 검출 · 기울기/어깨/피부 보정 · 크롭 · 인화시트 |
| `app.js` | UI 글루 |
| `index.html` / `style.css` | 화면 (모바일 우선, 다크모드 대응) |

## 데스크톱판과 다른 점

| | 데스크톱 (Python) | 웹 |
|---|---|---|
| 인물 분리 | u2net_human_seg (168MB, ONNX) | MediaPipe Selfie Multiclass (수 MB, WASM) |
| 얼굴 검출 | MediaPipe Tasks (Python) | MediaPipe Tasks (JS/WASM) — 같은 모델 |
| 피부 보정 | 양방향 필터 + 국소 중앙값 | 캔버스 블러 2단계로 근사 |
| 배포 | 490MB exe | 정적 파일 몇십 KB (모델은 CDN에서 로드) |

**인물 분리 모델이 다르다.** u2net 쪽이 머리카락 경계가 더 정밀하지만 168MB라
웹에 올릴 수 없다. MediaPipe 쪽은 256×256 출력이라 잔머리가 뭉개질 수 있다.
정밀도가 중요하면 데스크톱판을, 접근성이 중요하면 웹을 쓰면 된다.

모델은 Google 저장소와 jsDelivr에서 받아온다(첫 실행 때만, 이후 브라우저 캐시).
따라서 **첫 실행에는 인터넷이 필요**하다.

## 검증 (2026-08-11, 실제 사진)

브라우저에서 11개 규격 전부 확인:

```
jp-zairyu    354x472px   정수리 59px = 5.00mm (목표 5)
kr-passport  413x531px   정수리 47px = 3.98mm (목표 4)
jp-license   283x354px   정수리 35px = 2.96mm (목표 3)
jp-visa      531x531px   정수리 82px = 6.94mm (목표 7)
kr-meishi    591x827px   정수리 82px = 6.94mm (목표 7)
배경 순백(255,255,255) 확인 · 하단 인물 폭 100% · 분석 약 12초(첫 실행, 모델 로드 포함)
```

## 개발용 훅

콘솔에서 파일 선택 없이 테스트할 수 있다.

```js
await window.__loadTest('_test.jpg')   // 같은 폴더의 이미지를 불러와 처리
```

## 어깨 샘플 위치 (건드리기 전에 읽을 것)

`findShoulders()`가 어깨 높이를 재는 지점은 얼굴 폭의 **0.78배** 바깥이다.
1.15배로 뒀더니 팔을 뻗어 찍은 셀카에서 한쪽 샘플이 **치켜든 팔**에 떨어지고
반대쪽은 어깨 바깥 빈 곳에 떨어져, 실제 어깨선 차이가 아닌데도 기울기가
156px로 과대 측정됐다(데스크톱판에서 실측 후 양쪽 다 수정). 0.78이면 목에 가까운
진짜 어깨 경사를 잰다. 같은 사진에서 데스크톱 +4px / 웹 +3px 로 일치한다.
